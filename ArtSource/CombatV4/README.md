# Diverse 전투 연출 규칙

기존 위키의 액티브 언어 항목은 조작, 전달 형태, 궤적, 효과, 조건, 시간, 위치, 사건, 전술 역할과 대가를 나타낸다. 후보 하나는 이 어휘를 실제 실행 순서로 조합한다. 연출은 단계마다 판정 좌표와 시간을 받아 표시한다.

| 전달 형태 | 화면에서 읽혀야 하는 동작 |
| --- | --- |
| 전방 베기 · 직선 타격 | 무기가 지나가는 방향과 거리가 보인다. 실제로 맞은 대상에게만 별도의 절단선이나 충격이 남는다. 연쇄 직선은 실제 분기한 대상에게 연결선을 그린다. |
| 투사체 | 발사 섬광, 비행 본체, 궤적, 명중을 분리한다. 일반 탄은 보이는 무기 끝에서 출발한다. 직전 위치와 충돌 지점에서 이어지는 탄, 수렴탄은 해당 위치에 별도 발사점을 표시한다. |
| 폭발 · 지속 영역 | 폭발은 지면의 중심에서 벌어지고, 지속 영역은 타격 사이에도 범위가 남는다. 회복과 방어는 시전자에 붙는다. |
| 돌진 · 후퇴 · 점멸 | 출발과 도착의 좌표가 다르다. 돌진과 후퇴는 이동 경로를, 점멸은 짧은 출발 잔상과 도착을 보여 준다. |
| 방어 · 덫 · 장벽 | 방어는 실제 보호막과 함께 표시한다. 덫은 설치 모션, 대기와 무장, 발동을 구분한다. 장벽은 적 탄환이 막히는 선과 같은 자리에 설치한다. |

검은 베기 면과 대각 피격선, 단검은 짧게 끊기는 흠집, 봉은 끝이 앞서는 궤적과 둔중한 접촉 파편을 쓴다. 활은 가는 비행 궤적과 시위 소리, 총은 짧은 섬광과 반동 및 다른 발사음을 쓴다. 전용 AI 시트가 있는 경우 아이콘의 재질과 색을 공유하고, 내장 모션은 방향이나 타격 범위를 보조한다. 시트 처리 과정에서 투명 여백, 기준점, 프레임 간 실루엣, 비행 본체 두께를 검사하고 각 행을 따로 판정한다.

Q는 독립형이다. W·E·R은 같은 무기의 앞 슬롯에 발동 원인이 있을 때 독립형과 연계형을 함께 제안한다. 연계형도 자체 동작을 실행하며, 실제 명중·설치·도착 지점은 다음 연계에서 한 번 사용할 수 있다. 연계 후보 하단에만 앞 슬롯을 표시하며, 연계 가능한 동안 해당 HUD 키를 금색으로 표시한다. 모든 스킬은 개별적으로 장착하고 교환한다.

평타의 획 두께와 유지 시간, 명중 크기, 탄두와 잔상 폭은 전투 라이브러리에서 조절한다. 직선 연출은 길이를 유지하고 폭을 넓힌다. 덫과 영역의 바깥선은 판정 크기에 맞추고, 그 안의 발동 그림을 크게 보여 준다.

`impact_atlas.png`에는 봉 접촉, 단검 접촉, 총구 섬광, 결정 파열의 원본 네 행이 있다. `imagegen_prompt.txt`는 생성에 사용한 프롬프트다. `Tools/author_combat_cues.py`는 행별 기준점을 적용해 원본에서 Unity용 16개 프레임을 만든다. Unity에서 사용되는 크기와 타이밍은 `CombatVisualLibrary.asset`에 기록한다.
