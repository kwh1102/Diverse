# 월드 생성 버전 2

`SaveSystem.NewWorld()`에서 새 월드에 `generationVersion = 2`를 저장한다. 이전 세이브에서 이 필드가 없으면 0이며 기존 지형 및 무작위 장소 배치를 그대로 사용한다. 세이브 파일 형식의 `version`과 월드 생성 버전은 별도다. 생성 버전만으로 기존 세계를 자동 이전하지 않는다.

## 대형 지형

버전 2는 기존 WorldRules 값을 기준으로 산맥 생성 문턱 -0.025, 암벽 문턱 -0.025, 강 폭 ×4/3, 호수 문턱 -0.03을 적용한다. 현재 데이터 기준 0.38 / 0.82 / 0.016 / 0.70이다. 산맥과 수역의 노이즈 크기, 상단 봉우리 문턱, 자연 통로와 마을 안전구역은 유지한다. 도로 지형 회피와 해안 판정도 해당 생성 버전의 문턱을 사용한다.

## 필수 특수 장소

- 실제 등장하는 외곽 테마마다 서로 다른 2종을 배치한다. 시드에 따라 두 종류의 순서만 바뀐다.
- 첫 종류는 반경 170 안쪽, 나머지는 반경 170~320 사이에 전체 지형이 들어오도록 예약한다.
- 중앙 초원은 두 종류 모두 중앙 테마 영역에 배치한다.
- 장소 전체 반경과 진입 여유를 안개 경계에서 제외하고, 마을·기존 거점·다른 필수 장소와의 겹침을 피한다.
- 마른 땅과 도로 밖 후보를 우선 탐색한다. 물·도로 후보가 모두 좋지 않아도 장소를 누락하지 않으며 가장 영향이 적은 후보를 예약한다. 필요한 경우 장소 바닥을 확보한다.
- 무작위 후보 탐색 뒤에도 자리가 없으면 격자 전체를 재탐색한다. 현재 정의로 배치할 수 없는 잘못된 설정은 명시적 생성 오류로 처리한다.
- 고정된 `required:<종류 ID>`를 사용해 보상·발견 상태가 청크 로딩 순서에 따라 바뀌지 않는다.
- 첫 두 구역의 무작위 중복 장소를 막는다. 반경 320 이후에는 기존 무작위 탐험 장소가 추가로 생긴다.
- 필수 장소 진입로는 같은 안개 경계 안의 도로에 연결한다. 긴 진입로도 주변 지형 예약과 다리 판정에 반영한다.

## 이동 의도

스페이스 능력이 성공하면 일반 우클릭 경로와 적 추적은 지운다. 능력 종료 시 지도 목표가 있으면 새 위치에서 해당 목표로 경로를 다시 만들고, 지도 목표 없이 우클릭을 누르고 있으면 현재 커서로 이동한다. 둘 다 아니면 정지한다. 능력 실행 중에는 지도 이동의 막힘 판정을 진행하지 않는다. QWER 이동 능력의 일반 경로 복원과 스페이스 전용 후처리를 분리한다.

이번 수정은 요청에 따라 테스트 및 Unity 실행 없이 반영했다.
