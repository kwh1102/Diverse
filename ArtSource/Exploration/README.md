# 탐험 확장 아트 원본

2026-11-02. 내장 `image_gen` 도구로 생성했다. CLI/API fallback은 사용하지 않았다. 기존 `ArtSource/WorldOverhaul/props.png`, `scenery.png`, `hero.png`를 스타일/정체성 참고로 사용했다. 생성 시 투명 배경을 요청했으며 알파를 유지한다.

- `props.png`: 4열 × 9행, 테마별 소품 4종씩 총 36종.
- `anchors.png`: 3열 × 3행, 큰 탐험 장소의 중심물 9종.
- `states.png`: 4열 × 1행, 기본 대기/짧은 눈 깜빡임/닫힌 상자/열린 상자.

행/테마 순서: 초원, 숲, 화산, 수정, 빙하, 협곡, 요새, 거울, 늪. 생성 시트는 게임에서 로드하지 않는다. `WorldExplorationArt.cs`가 투명 여백에서 셀 경계를 찾아 원래 66색 팔레트, 16 PPU, Point 필터, 이진 알파의 네이티브 PNG로 가져온다. 상자 쌍은 실제 폭 22px와 바닥 피벗을 공유한다. 기존 이름의 `.meta`는 유지한다. 관리 목록은 `ArtSource/WorldOverhaul/managed.txt`에 합친다.

재적용: **Diverse → Art → Import Exploration Art and Corrected States**. 전체 아트 가져오기도 이 원본이 존재하면 마지막에 같은 수정 프레임을 적용한다. 장소·지형 데이터 설치는 별도 **Diverse → World → Apply Exploration Expansion** 메뉴다. 조정한 데이터가 초기화되는 명시적인 기본값 설치 메뉴다.

아래 세 요청이 최종 생성 프롬프트다. 실제 게임 배치·충돌·높이·재질은 별도의 편집 가능한 데이터와 렌더러에서 구성한다.
