# 다른 세션에 붙여 넣을 프롬프트

> Diverse 프로젝트의 imagegen 스킬로 `ArtSource/Parts/image_manifest.csv`에 있는 T1 파츠 32종을 개별 투명 PNG로 제작해 줘. 기존 게임 캐릭터를 참고한 귀여운 도트 RPG 스타일이며, 단순한 어린이 그림보다 정교하고 화려한 스킬 아이콘보다 차분하게 맞춰 줘. 큰 실루엣, 짙은 보라 외곽선, 재질별 3~4톤, 절제된 금속·유리·천 표현, 발광·입자·그라데이션·문자·아이콘 프레임 제외. 최종 네이티브 크기는 32×32, Point 필터, 실제 알파 투명도. 매니페스트의 최종 경로로 저장하고 기존 .meta GUID를 유지해 줘. 합성용 투명 장식 `trim_t2.png`~`trim_t5.png`도 48×48로 만들되 중앙 36×36과 아래 재료 배지는 가리지 않게 해 줘. 완료 후 `Tools/author_part_catalog.py`로 원본 연결과 도감을 갱신해 줘. 게임 실행·컴파일·테스트는 하지 마.

이미지를 생성하기 전 `CLAUDE.md`, imagegen 스킬, `Docs/Parts.md`를 읽는다. 32개가 한 장에 들어간 그림으로 대체하지 않는다. 각 파일을 개별 에셋으로 제공하고 모든 결과를 프로젝트 안에 저장한다.

## 인수 조건

- 32개 T1 파일명과 능력상 물체의 의미는 매니페스트를 따른다.
- 기존 원본 16개는 품질 교체 대상이다. 새 원본이 생기기 전까지는 기존 PNG를 임시로 사용한다.
- 투명 장식은 테두리 안쪽의 작은 연결쇠·보석·금속 장식만 사용한다. 파츠 아이콘 자체에 사각 UI 프레임을 넣지 않는다.
- Unity TextureImporter는 Sprite(Single), Point, readable, uncompressed, alpha transparency로 설정한다.
- 합성 결과를 수천 장 생성하지 않는다. T1 원본과 4개 등급 장식만 제작한다.
