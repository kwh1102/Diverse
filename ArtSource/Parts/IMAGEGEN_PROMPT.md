# 다른 세션에 붙여 넣기

> Diverse에서 imagegen 스킬로 `ArtSource/Parts/image_manifest.csv`의 파츠 아트 176개(T1 32종 + 진화 144종)를 제작해 줘. 먼저 `CLAUDE.md`, `Docs/Parts.md`, `Docs/PartEvolution.md`를 읽고 **현재 고유 능력과 매니페스트의 모티프**에 맞춰 그려 줘. 룬 조준경은 같은 표적의 후속 탄, 갈대 관은 긴 비행, 나선 노즐은 나선 홈, 중력석은 안쪽으로 끌림, 메아리 방울은 이전 슬롯으로 돌아가는 시간을 구분해 줘. 파츠가 스스로 공격하는 그림은 피하고, T2~T5는 두 계열이 융합된 하나의 새 도구로 그려 줘. 같은 계열 쌍은 등급이 오를수록 실루엣·재질이 발전하게 해 줘. 귀여운 탑다운 도트 RPG, 읽기 쉬운 큰 픽셀 덩어리, 짙은 보라 외곽선, 재질별 3~4톤, 적당히 정교한 금속·유리·천 표현. T1 32×32 / 진화 48×48, 실제 알파 투명 PNG. 배경·문자·UI 테두리·과도한 발광·입자·그라데이션 제외. 작은 묶음으로 제작해 매니페스트의 개별 PNG 경로에 저장하고 기존 .meta GUID를 유지해 줘. Unity Sprite Single / 16 PPU / Point / readable / 무압축으로 연결하고 T1 sprite 경로를 각 ID로 갱신한 뒤 `Tools/export_wiki.py`로 위키를 갱신해 줘. 능력·수치·레시피와 초기 저작 스크립트는 건드리지 말고 게임 실행·컴파일·테스트도 하지 마.
