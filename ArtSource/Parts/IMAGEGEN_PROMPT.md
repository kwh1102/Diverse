# 다른 세션에 붙여 넣기

> Diverse 프로젝트에서 imagegen 스킬로 `ArtSource/Parts/image_manifest.csv`의 파츠 아트 176개(T1 32종 + 계열 조합·등급별 진화 144종)를 제작해 줘. 먼저 `CLAUDE.md`, `Docs/PartEvolution.md`와 매니페스트를 읽어 줘. 귀여운 탑다운 도트 RPG 스타일, 선명한 큰 실루엣, 짙은 보라 외곽선, 재질별 3~4톤, 적당히 정교한 금속·유리·천 표현으로 통일해 줘. T2~T5는 재료 그림을 붙이지 말고 두 계열의 특징을 융합한 하나의 새 도구로, 등급이 오를수록 실루엣과 재질이 발전하게 그려 줘. T1은 32×32, 진화는 48×48, 실제 알파 투명 PNG. 배경·문자·UI 테두리·과도한 발광·입자·그라데이션은 제외해 줘. 작은 묶음으로 제작하되 최종적으로 매니페스트의 개별 PNG 경로에 저장하고 기존 .meta GUID는 유지해 줘. Unity Sprite Single / 16 PPU / Point / readable / 무압축으로 연결하고, T1의 sprite 경로를 각 ID로 갱신한 뒤 `Tools/export_wiki.py`로 위키를 갱신해 줘. 데이터 재저작 도구로 능력 수치를 초기화하지 말고, 게임 실행·컴파일·테스트도 하지 마.
