# AI 액티브 · 고정 파츠

## 성장 보상과 후보 선택

Q/W/E/R은 각각 레벨 5/10/15/20에 획득한다. 나머지 레벨업은 T1 파츠를 지급한다. 여러 레벨이 오르면 레벨 순서대로 보상을 받는다. 파츠 32종과 합성 결과 계산은 [Parts.md](Parts.md)를 참고한다. 패시브 기술 언어와 AI 파츠 생성은 사용하지 않는다.

액티브 보상 화면은 해당 슬롯의 후보 3개와 프롬프트 입력창을 제공한다. 카드에는 무기 유형, 슬롯, 조작, 발동 조건과 결과를 표시한다. 보유 무기 유형을 우선하며 프롬프트로 보유 유형을 지정할 수 있다. 원하는 후보를 고정하면 재요청과 다시 뽑기에서 유지한다. 선택 전에 후보 3개의 아이콘을 한 번에 준비한다. 선택한 기술에는 전투 규칙별 내장 이펙트가 있다. AI가 연결되어 있으면 선택한 기술에 한해 보조 그림을 만들고 검사한다. 보조 그림을 쓸 수 없으면 내장 연출로 장착한다.

후보와 고정 상태는 저장한다. 레벨 보상에서 ‘나중에 선택’을 누르면 같은 후보를 보존한다. 대장간에서는 이미 레벨 조건을 충족한 슬롯을 유료로 추가 의뢰할 수 있으며 비용은 선택 시 지불한다. 새 무기를 얻어도 QWER을 자동 생성하지 않는다.

## 액티브 기술 언어

후보는 `ActiveTechniques`에 등록된 20가지 전투 규칙에서 고른다. 같은 선택 화면에 같은 규칙을 두 번 제안하지 않는다. 무기 계열을 우선하며 탄환 압수와 탄피 점화는 총으로 제한한다. AI는 후보마다 허용된 기술 ID를 골라 이름, 색, 아이콘과 보조 이펙트의 소재를 제안한다. 기술별 사거리, 범위, 지속시간과 위력은 `AbilityRules.asset`에 둔다. 로컬 후보도 동일한 전투 규칙을 사용한다.

| 무기 계열 | 전술 규칙 |
|---|---|
| 검 | 칼등 반사, 벽쐐기, 맞부딪치기, 방패 틈 벌리기 |
| 활 | 길목 봉합, 끌매듭, 울림촉, 회수 사선 |
| 총 | 탄환 압수, 벽면 파쇄, 탄피 점화, 숨 고르기 |
| 봉 | 공명 닻, 되감기 인장, 쌍문 전도, 밀물과 썰물 |
| 단검 | 그림자 교대, 문턱 덫, 추적선 끊기, 빈틈 잠금 |

즉시형은 입력 프레임에 동작을 시작한다. 재입력형은 같은 키로 표시된 대상이나 설치 지점에 후속 조작을 한다. 문턱 덫은 설치 동작 후 무장하며 지정한 방향으로 경계를 넘을 때 설치 지점에서 터진다. W/E/R 후보는 앞 슬롯의 명중·설치·도착 신호로 자기 사거리와 작동 시간을 늘리거나, 신호 지점 가까이를 조준해 그 지점에 후속 기술을 설치할 수 있다. 신호가 없을 때에도 해당 기술의 기본 동작은 실행된다.

이전 단계 배열은 획득한 스킬을 읽는 데 사용한다. 기존 직선 공격과 손에서 발사하는 투사체는 현재 무기에서 시작한다. 직선은 벽에 닿는 지점까지 판정한다. 이전 덫의 적중 후 베기는 덫 자리에서 처리하는 피해에 합친다. 기존에 획득한 스킬과 완성된 그림은 유지하며 새 후보에는 기술 ID를 사용한다.

## 아이콘과 전투 이펙트

다음 미수령 Q/W/E/R 보상은 해당 레벨 4단계 전부터 전투 중에 후보 3개와 아이콘을 사전 준비한다. 준비 중에도 전투와 입력은 유지되며 보상 창은 같은 결과를 인계받는다. 아직 준비 중이라면 진행 중인 요청이 끝날 때까지 기다린다. 다음 슬롯 하나만 준비하고 무기/파츠 재장착으로 요청을 반복하지 않는다. 대장간 별도 의뢰는 진행 중인 사전 요청을 마친 뒤 시작한다. 후보와 아이콘 상태를 세이브하며, 중단된 요청은 자동 재결제 없이 로컬 후보/아이콘으로 복구한다. 선택한 기술 하나에 보조 전투 그림을 요청할 수 있어 해당 요청이 진행되는 동안 선택 대기가 남는다. `AbilityRules.active.prefetchSkills`와 `skillPrefetchLeadLevels`에서 조정한다.

실제 아이콘에서 외곽선·음영·주조색·하이라이트를 추출한다. 기술별 내장 이펙트는 설치 표시, 판정 경로, 발동, 필요한 탄체를 구분하고 무기 끝·실제 충돌점·설치 좌표를 따른다. 생성 시트는 선택한 기술의 발동 장면에 겹쳐 쓰는 4프레임 소재다. 프롬프트에는 해당 기술의 실루엣과 아이콘 팔레트를 전달한다. 이미지 처리기는 배경, 경계 침범, 정지 반복을 검사하며 통과한 그림을 저장한다. 기존 스킬용 시트와 원본은 기존 서명에 따라 재사용한다.

후보 아이콘은 **gpt-image-2.5-flare / low / 1024×1024** 2열×2행 한 장을 사용한다. 위 왼쪽, 위 오른쪽, 아래 왼쪽이 후보 순서다. 최종 아이콘은 32px, 12색이다. 전투 보조 시트 기본 품질은 medium이며 모델과 품질은 `AbilityRules.asset`에서 수정한다. 실패 시 해당 기술의 로컬 그림을 표시한다. 원본이 있으면 무료 재처리할 수 있고, 새 유료 요청은 인벤토리에서 직접 실행한다.

후보 텍스트를 먼저 저장하고 아이콘 요청 시작 여부도 저장한다. 앱이 이미지 요청 도중 종료되면 후보는 복구하되 자동으로 유료 재요청하지 않고 로컬 도트로 마무리한다. 완료된 후보의 과정 로그와 아이콘은 재사용한다.

ImageClient는 응답의 usage로 이미지 입력 텍스트/이미지 토큰과 출력 토큰 비용을 계산한다. usage가 없는 응답은 추정임을 표시하고, 가격표가 없는 모델은 비용 미상 건수로 따로 누적한다. 스튜디오/무기 이미지에도 같은 집계를 적용한다. 요금 근거: [OpenAI 2.5 Flare 모델 문서](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare). 실제 청구액은 공급자 대시보드가 기준이다.

## 무기 유형과 교환

유형은 검·활·총·봉·단검이다. 무기 데이터가 유형을 정하고 외형은 별도로 저장한다. 각 유형의 QWER·파츠 좌표와 외곽선 색은 데이터에서 정한다. 모든 배치 무기에 실제 칸 모양의 외곽선을 표시하고 사용 중인 무기는 더 두껍게 표시한다. 드래그 미리보기도 같은 실제 칸을 따른다.

교환은 같은 유형의 같은 슬롯끼리 가능하다. Q는 단독으로 동작하며, W·E·R은 같은 무기의 앞 슬롯이 남긴 명중·설치·도착으로 연계할 수 있다. 후보 카드 하단은 실제 연계가 있는 후보에만 연결 슬롯을 표시한다. 스킬마다 이동·교환·폐기를 처리하고, 앞 슬롯이 비면 후속 스킬의 기본 동작은 계속 사용할 수 있다.

초기 저장의 묶음 스킬은 읽을 때 개별 스킬로 바꾼다. 앞 슬롯의 표식을 소비하던 경우에는 호환되는 명중 연계로 변환하고, 표식이 없으면 아무 동작도 할 수 없던 스킬에는 기본 동작을 복구한다. 스킬 아이템과 슬롯, 완성된 그림은 보존한다.

이전 고정 파츠는 등급에 맞는 T1 재료 구성으로 이관한다. 이전 패시브 프로그램은 실행하지 않는다. 이전 24종 스킬은 로컬 액티브로 이관하고, 이전 3×3 장착 배치는 유형별 공간으로 재배치한다. 공간이 부족한 아이템은 수령 대기에 보존한다.

화면 검증: `Diverse.EditorTools.SkillUiReview.RunBatch`가 실제 Game 씬을 임시 세이브/AI 비활성 상태로 열어 설명 스크롤·모든 아이템 동작 버튼·채팅·사전 준비 인계·저장된 AI 스킬 연출을 캡처한다. 결과는 `Logs/SkillUiReview/<실행 시각>/`에 남는다. 이 검증은 실제 API 생성 품질·지연이나 모든 스킬 조합을 보장하지 않는다.

전체 유형·수치·진화 정의와 원본 필드는 [로컬 개발 위키](Wiki/index.html)에서 검색한다.
