# 탐험 장소 확장

목표는 이동 중 서로 다른 공간을 발견하고, 통로와 갈림길을 따라 기록·물자·보물을 찾는 경험을 늘리는 것이다. 새 테마를 더해 5구역 규칙을 바꾸는 작업은 아니다.

## 추가 콘텐츠

9개 아트 테마에 소품 4종씩 36종, 큰 중심물 9종을 추가했다. 12개 공간 구성으로 18개 장소 변형을 제공한다. 일반 세계에는 초원과 무작위로 선택된 5개 구역의 장소가 등장한다.

| 테마 | 장소 변형 |
|---|---|
| 초원 | 물레방앗간 마을, 들꽃 폐허 |
| 숲 | 덩굴 미로, 뿌리 아래 동굴 |
| 화산 | 식어버린 주조장, 잿빛 용암 협곡 |
| 수정 | 결정 관측소, 수정 채석장 |
| 빙하 | 푸른 얼음 동굴, 눈에 묻힌 탐사대 |
| 협곡 | 바람 깎인 협곡, 모래바람 쉼터 |
| 요새 | 무너진 성문 지구, 성벽 밖 보급 마을 |
| 거울 | 깨진 거울 정원, 잊힌 반사의 성소 |
| 늪 | 늪지 나무길, 버섯 고목 군락 |

동굴·협곡·채석장은 실제 높이와 통로를 가진 지형이다. 정글은 꺾이는 길과 고목·식생 군집, 마을은 건물과 상인·주민, 습지는 물과 판자길을 갖는다. 동굴은 열린 지붕으로 표현한 같은 월드 안의 탐험 공간이며 별도의 실내 씬으로 전환하지 않는다.

모든 장소에 조사 기록과 보물이 있다. 일부에는 상인·주민·약초가 있다. 기록은 한 번만 세계 연대기에 남고, 발견한 장소는 지도에 표시되며 조사 후 색이 바뀐다. 보물·약초는 기존 보상 규칙과 저장 플래그를 사용한다. 청크를 다시 불러와도 상자와 조사 상태를 복원한다.

## 편집 위치

- `Data/WorldRules.asset → Exploration places`: 장소 간격, 여유 공간, 테마별 18개 데이터.
- 각 장소의 `grounds`: 사각형·타원·마름모 지형 레이어, 높이/재질, 위치·범위·모서리 깎임. 마지막으로 일치하는 레이어가 우선한다.
- 각 장소의 `props`: 이미지 키, 위치, 실제 충돌 크기, 조사·상자·상인 등 역할.
- `Data/Themes/*.asset → decor`: 필드에 추가되는 지역 소품. 기존 장식 간격과 실루엣 검사를 따른다.
- `Data/ArtStyle.asset → Hero idle`: 기본값 4.8초마다 0.08초 깜빡임. 대기 이미지는 6개 코스튬과 토끼 주민에 맞춰 가져온다.

**Diverse → World → Apply Exploration Expansion**은 기본 배치 데이터를 다시 설치하는 명시적인 메뉴다. Inspector에서 조정한 장소 데이터를 다시 기본값으로 바꾸므로, 단순 이미지 재가져오기는 **Art → Import Exploration Art and Corrected States**를 사용한다. 원본·생성 프롬프트는 `ArtSource/Exploration/README.md`에 있다.

## 생성·연결 규칙

`ExplorationLayout`이 56타일 셀 좌표와 시드로 장소를 고른다. 생성 과정은 높이/최종 타일을 다시 조회하지 않아 재귀와 로딩 순서 의존성을 피한다. 기존 도로, 시작 마을, 보스 장소와 강을 침범하지 않도록 후보를 제외한다. 일반 소품과 작은 구조물은 큰 장소의 전체 범위를 비운다. 장소 주변의 짧은 여유 공간과 접근로만 자연 높이를 낮추고, 넓은 원형 평탄화는 하지 않는다. 기본 접근로는 가장자리에서 18타일, 반폭 1.1타일이며 물을 만나면 테마의 액체에 맞춰 다리/얼음으로 연결한다. 장소 내부의 지형 레이어는 화면과 충돌에 함께 사용한다.

시작 초원의 내부는 노이즈 값의 끝점과 무관하게 초원으로 유지한다. 테마와 보조 재질은 4타일 단위로 고르고 주변 지지 여부를 검사해 고립된 작은 구획을 합친다. 물/바위의 큰 지역 경계와 시작 지역의 기존 선택 규칙은 유지한다. 장식용 바닥 색 얼룩은 다른 지형 타일이 아니다.

새 일반 세계는 여전히 8개 전투 성향 중 5개를 중복 없이 선택하고 연결된 테마를 배치한다. 시작 초원은 별도다. 기존 세계는 저장된 선택을 유지한다. 이번 변경은 같은 시드의 지형/장소 모양을 바꾸지만 실제 사용자 저장 파일을 검증 도구가 수정하지 않는다.

## 검증

`ExplorationChecks.RunBatch`는 레이아웃의 입구·상호작용 접근성, 32개 시드의 5구역 선택과 초원 보호, 역순 생성, 상자 실제 폭/피벗, 깜빡임 노출 시간, 기존 청크/아트 검사를 실행한다. `ExplorationCapture.RunBatch`는 실제 Game 씬에서 18개 장소를 촬영하고 길찾기·발견·일회성 조사·상자 개봉·세계 기억 직렬화와 청크 재로딩을 검사한다. 두 도구 모두 검증용 데이터만 쓴다.

기록과 실제 화면: `Logs/Exploration/`. 편집 확인은 `Scenes/Game.unity`를 열어 Play. 배치 변경 후 기존 실행 중인 월드는 다시 시작해 새 생성기와 캐시를 사용한다.

## 후속 빠른 수정 — 사용자 요청으로 테스트 생략

연결된 절벽은 낮은 단과 높은 단을 함께 탐색해 지형 전체에 하나의 재질을 배정한다. 지역/청크 경계에서 윗면·벽면·상단 장식이 서로 다른 테마로 갈리지 않게 같은 결과를 사용한다. 큰 산맥은 탐색 한도를 넘으면 공통 중립 재질로 통일하고, 결과 캐시에는 상한을 둔다. 이 절벽 재질 수정도 실행·컴파일·테스트 없이 적용했다.

마을은 `WorldRules.settlementGround`의 흙 구획과 `settlementRoad`의 석재 길을 사용해 요새 바닥과 구분한다. 미니맵에도 장소/마을 표시를 추가했고, 중심이 인접 지역에 있는 큰 장소도 발견하도록 조회 범위를 바로잡았다. 기본 36×34 대기 그림의 비대칭 눈은 알려진 얼굴 픽셀 배치에 한해 런타임에서 한 번 보정해 캐시한다. 다른 크기/얼굴 배치는 건드리지 않는다.

테마는 물·절벽과 같은 연속된 지역 경계를 따르게 바꾸고, 보조 바닥은 잔디 계열 안에서만 허용한다. 옛 야영지·소굴·묘지·나루터의 고정 흙/잿빛 바닥도 해당 테마 재질을 사용한다. 산지 문턱을 0.855→0.845, 산지 마스크를 0.42→0.405로 소폭 낮췄다. 이 후속 수정은 게임 실행·컴파일·테스트를 진행하지 않았다. Play를 종료하고 다시 시작해야 새 지형 캐시와 표시가 적용된다.
