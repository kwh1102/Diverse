# 인벤토리 · 파츠 · 계승

I로 인벤토리를 연다. 가방 크기는 이동 유형, 무기 주변 공간은 무기 유형에 따라 달라진다.

## 무기와 슬롯

검·활·총·봉·단검마다 QWER 좌표와 파츠 칸이 다르다. QWER 칸에는 같은 유형의 해당 슬롯 스킬만, ◇ 칸에는 파츠만 장착한다. 무기들의 예약 칸은 겹칠 수 없고 전체 모양이 가방 안에 있어야 한다.

모든 무기의 실제 칸 범위를 유형별 색으로 표시한다. 사용 중인 무기는 두꺼운 선으로 구분한다. 드래그 미리보기는 같은 칸 모양을 사용하며 배치 가능 여부는 초록/빨강 채움으로 표시한다. 선은 칸 경계를 중심으로 그리고 끝점을 겹쳐 오목한 모서리도 이어 붙인다. 색은 AbilityRules의 Weapon Shapes에서 편집한다.

같은 유형의 Q는 Q, W는 W, E는 E, R은 R끼리 교환한다. 앞 슬롯을 참조하는 스킬도 개별적으로 이동한다. 무기를 옮기면 장착물이 따라가고 실패하면 원래 배치로 돌아간다. 보관 중인 아이템에는 전투 효과가 없다.

무기 사용 버튼 또는 우클릭으로 활성 무기를 바꾼다. 공간이 부족한 아이템은 수령 대기에 보존한다. 마지막 배치 무기는 버릴 수 없다. 무기를 버리면 장착물은 수령 대기로 보존한다. 스킬을 버리면 선택한 스킬만 제거된다.

## 파츠와 합성

레벨업 파츠 후보에는 T1만 등장한다. 5레벨 전에는 평타·방어·Space 이동으로 활용하는 12종, 5레벨부터는 액티브 보조를 포함한 32종이 등장한다. Q/W/E/R의 5/10/15/20레벨 보상은 유지한다. 같은 등급의 파츠 두 개를 합쳐 T2~T5를 얻고 같은 종류와 다른 종류 모두 합성할 수 있다. 재료의 모든 T1 종류와 수량을 보존해 고유 동작과 수치를 계승한다. 같은 재료 구성은 합성 순서와 관계없이 같은 결과다.

합성 화면에서 두 재료를 고르면 결과 능력과 재료를 자동으로 미리 보여준다. 골드가 없어도 미리 볼 수 있고, 확정할 때만 두 파츠와 골드를 소비한다. 보유/필요 골드와 합성이 불가능한 이유(다른 등급, 동일 아이템 중복 선택, 최고 등급, 골드 부족)를 표시한다. 기본 비용은 30 + 재료 등급×25 G이며 T5는 합성할 수 없다. 합성에는 AI와 이미지 API를 사용하지 않는다. 동일한 전체 구성을 중복 장착하면 하나만 적용한다. 자세한 목록·등급별 종류 수·공식은 [Parts.md](Parts.md)를 참고한다.

파츠 아트 생성은 보류했다. T1은 기존 PNG를 임시 사용하며 T2~T5는 계열 조합·등급별 전용 그림 경로를 사용한다. 파일이 없으면 준비 중 아이콘을 표시한다. 진화는 재료 계승에 조건부 액티브 보조 특성을 더한다. [진화 규칙](PartEvolution.md)을 본다. 다른 세션의 이미지 작업 지침은 ArtSource/Parts/IMAGEGEN_PROMPT.md에 있다.

## 액티브와 보상

Q/W/E/R은 각각 레벨 5/10/15/20에 3개 후보 중 선택한다. 나머지 레벨업은 T1 파츠를 지급한다. 액티브 후보에는 무기 유형과 조작을 표시하고 하단 프롬프트로 고정하지 않은 후보를 다시 요청할 수 있다. 후보 아이콘은 선택 전에 image-2.5 low 시트 한 장으로 준비하고 선택한 기술에는 전용 내장 연출을 적용하고, AI 연결 시 선택한 기술 한 개의 보조 그림을 만들어 검사한다. 대장간 추가 의뢰도 이미 해금한 슬롯만 가능하다. W·E·R 후보는 같은 무기의 앞 슬롯을 참조할 수 있다. 연계가 있는 후보 하단에는 참조 슬롯을 표시한다. 성장 보상 채팅의 대화 내역은 입력창 바로 위까지 채운다.

새 무기를 받으면 평타 전용 아트만 생성한다. 기존에 보유한 같은 유형·슬롯 스킬을 장착하거나 대장간에 추가 의뢰한다. 생성 실패 아이콘은 아이템의 ‘스킬 그림 생성’으로 직접 재요청한다. 중단된 이미지 요청은 이어하기에서 유료로 재요청하지 않는다. [ActiveSkills.md](ActiveSkills.md)에 기술 언어·다양성 검사·과정 로그·이미지 비용 정책을 정리했다.

추가 무기 획득 조건은 레벨 5 + 세계 보스 1회 처치다. 유적·보물 상자·대장간에서 획득한다. 사망하면 파츠 하나를 다음 삶의 유산으로 선택하며 재료 구성·등급·원래 소유자를 보존한다.

우측 설명란은 아이콘·이름·유형/등급을 상단에 고정하고 본문이 남은 높이를 채운다. 장착·사용·수령·스킬 그림 생성·버리기 버튼은 종류와 관계없이 하단에 모으며, 필요한 버튼만 공간을 차지한다. 스크롤바를 항상 표시하며 아이템을 바꾸면 본문을 맨 위로 되돌린다. 기존 비활성 프리팹에서 스크롤 참조를 놓치던 이관 오류를 수정했고, UI 개정 5에서 실제 헤더·스크롤·스크롤바 참조가 연결되었는지도 확인한다.

전체 목록과 무기 공간 도식은 [로컬 개발 위키](Wiki/index.html)에서 확인한다.
