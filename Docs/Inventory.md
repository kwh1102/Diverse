# 인벤토리 · 파츠 · 계승

I로 인벤토리를 엽니다. 가방 크기는 이동 유형이, 무기 주변 공간은 무기 유형이 정합니다.

## 무기와 슬롯

검·활·총·봉·단검마다 QWER 좌표와 파츠 칸이 다릅니다. 표시된 QWER 칸에는 같은 유형의 해당 슬롯 스킬만, ◇ 칸에는 파츠만 장착합니다. 무기끼리는 실제 예약 칸이 겹칠 수 없고 주변 공간 전체가 가방 안에 있어야 합니다. 활성 무기의 실제 외곽을 초록 선으로 표시합니다.

드래그로 배치·교환합니다. 같은 유형의 Q는 Q, W는 W, E는 E, R은 R끼리 교환합니다. 종속 스킬은 양쪽 무기의 관계를 모두 보존하도록 함께 이동하며, 드래그 중 안내에 이동 슬롯을 표시합니다. 독립적인 상태 연계는 개별 교환이 가능합니다. 무기 이동에는 장착물이 따라가며, 실패 시 원래 배치로 돌아갑니다. 보관 칸의 아이템은 전투 효과를 내지 않습니다.

무기 사용 버튼 또는 우클릭으로 활성 무기를 바꿉니다. 공간이 부족한 아이템은 수령 대기에 보존합니다. 마지막으로 배치된 무기는 버릴 수 없습니다. 무기를 버리면 장착물을 수령 대기로 보존하고, 종속 스킬을 버리면 같은 묶음 전체를 버립니다.

## 고정 파츠

파츠는 고정 16종 목록과 미리 제작한 32px 도트 PNG를 사용합니다. 레벨업 선택 창은 고정 목록 중 후보를 제시합니다. 파츠의 AI 생성·자유 합성·이야기꾼을 통한 패시브 프로그램 편집은 제거했습니다. 동일 파츠는 가장 높은 등급 하나만 적용합니다.

같은 종류·같은 등급의 파츠 두 개를 고르면 해당 파츠의 다음 등급을 미리 봅니다. 합성 확정 시에만 재료 두 개와 골드를 소비합니다. 비용은 Inventory 데이터의 기준을 따르며 기본 30 + 등급×25 G, 최대 T8입니다. API 없이도 합성할 수 있습니다.

## 액티브와 아트

레벨업·대장간 스킬 습득과 추가 무기 획득 후에 AI가 액티브를 설계합니다. 각 스킬의 아이콘·투사체·시전·명중·궤적·발사 효과는 독립된 image-2.5 시트에서 생성하고 아이템에 저장합니다. 무기 디자인에서 생성하는 공격 아트는 평타 전용입니다. 실패한 스킬 이미지는 아이템을 선택한 뒤 스킬 그림 생성으로 재요청합니다.

생성 중인 아이템의 교환은 완료 후 가능합니다. 생성 중 저장한 경우 대기 상태를 보존해 이어하기에서 다시 요청합니다. API를 사용할 수 없으면 실행 가능한 로컬 조합과 임시 도트가 제공됩니다. 자세한 생성·밸런스·종속 규칙은 [ActiveSkills.md](ActiveSkills.md)를 참조합니다.

## 획득 · 계승

추가 무기는 기존 조건인 레벨 5 + 세계 보스 1회 이후 유적·보물 상자·대장간에서 획득합니다. 디자인 미리보기에서 무기를 받으면 QWER 생성이 별도로 시작됩니다. 소모품·무기 해금·유산 비용과 한도는 Resources/GameDatabase.asset의 Inventory에서 조정합니다.

사망 시 파츠 하나를 다음 삶의 유산으로 선택합니다. 원래 소유자 이름과 등급을 보존하고 중복 회수는 막습니다. 이전 패시브는 고정 목록의 파츠로, 이전 액티브는 조합 스킬로 이관합니다. 이전 3×3 배치는 유형별 공간으로 다시 배치하며 공간 부족 아이템은 수령 대기에 둡니다.
