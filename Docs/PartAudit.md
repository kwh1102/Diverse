# 파츠 아트 제작 전 능력 검토

검토에서 발견한 중복을 수정해 T1 32종에 서로 다른 고유 능력을 구현했다. 전체 현재 목록은 [파츠 도감](Parts.md)을 본다. 아래 판정과 유사성 목록은 개편 전 기록이다.

## 개편 반영 결과

- T1 32종을 각각 별도 고정 규칙으로 구현했다. 룬 조준경(동일 시전 후속 탄), 갈대 관(비행 거리), 나선 노즐(실제 궤적), 중력석(실제 끌기 강화), 메아리 방울(직전 슬롯 쿨다운 회수)을 구분했다.
- 초반 12종은 평타·피격·완벽 회피·Space 이동으로 작동한다. 5레벨 전 보상에는 이들만 등장한다. 나머지 20종은 5레벨부터 후보에 합류한다.
- T2~T5는 모든 재료 고유 능력을 계승한다. 같은 능력의 중복 강화와 개별 출력에 상한을 둔다. 144개 이름/외형은 여전히 계열 쌍 36개 × 4등급으로 공유하며, 구성 재료가 다르면 계승 동작도 다르다.
- 모든 동작은 고정 코드와 데이터로 정의하며 런타임 AI나 자동 스킬 시전을 추가하지 않았다. 불씨의 화상과 투사체 보정은 직접 사용한 액티브에만 적용한다.
- 제작 매니페스트와 [이미지 생성 프롬프트](../ArtSource/Parts/IMAGEGEN_PROMPT.md)에 새 모티프를 반영했다. 이미지 생성은 하지 않았다.
- 임시 Game 씬에서 보상 필터, 실제 Combat.Hit의 치명타/회복, 쿨다운 회수, 투사체 보정, 합성/저장 복원, 제어 상태와 상한을 검증하고 초반 보상·T2/T5 설명 화면을 캡처한다. 실제 API는 사용하지 않는다. 장시간 플레이 밸런스는 별도 조정 대상이다.

## 개편 전 판정

모든 파츠가 서로 다른 플레이를 만든다는 기준에는 아직 미달한다. 아트 176개를 확정하기 전에 능력 설계를 수정하는 것이 좋다.

| 확인 항목 | 현재 상태 |
|---|---|
| T1 수치까지 완전히 같은 효과 | 룬 조준경과 갈대 관: 투사체 액티브 피해 +4.5%, 액티브 사거리 +3.5% |
| T1 고유 효과 벡터 | 32종 중 31개. 수치 벡터가 다르다는 뜻이며, 고유 동작 31개라는 뜻은 아님 |
| T1 구성 방식 | 기존 스탯/액티브 보조 수치 한두 개. 파츠별 독자적인 입력·위치·적중 규칙은 없음 |
| 진화 144종 | 계열 쌍 36개 × 4등급. 같은 계열 쌍은 등급이 올라도 조건/효과 종류가 같고 수치만 상승 |
| 진화 효과의 범위 | 조건을 만족하면 피해·사거리·제어 시간·보호막·회복·쿨다운 수치 추가. 스킬 경로나 조작을 바꾸는 독자 동작은 없음 |

## 유사성이 큰 묶음

- 집중 렌즈/분광 핵/홍옥 핀/호박 거울: 액티브 피해에 기존 보조 수치를 섞는 방식.
- 태엽 시계/은빛 톱니/메아리 방울/모래시계 구슬/나선 노즐: 재사용 감소에 공격 속도·보호막·경험치·투사체 피해를 붙이는 방식.
- 매깃 화살깃/매눈 조준경/룬 조준경/나선 노즐/갈대 관: 투사체 피해와 다른 기존 수치의 조합.
- 바람 장화/비단 손잡이/깃털 고리/산들바람 리본: 이동 속도·공격 속도·대시 재사용 수치의 조합.

조합별 용도와 효율 차이는 있지만, 장착 후 새로운 행동을 배우는 차이는 작다.

## 이름과 실제 기능의 차이

- 나선 노즐은 탄환을 나선으로 움직이지 않는다.
- 메아리 방울은 스킬을 되울리거나 반복하지 않는다.
- 중력석은 적을 끌어당기지 않는다.
- 서리 결정은 자체적으로 냉기를 부여하지 않는다.
- 범위 계열은 현재 주로 사거리를 늘리며 공격 면적을 넓히는 전용 기능이 아니다.
- 치명타 계열의 추가 진화 특성은 직선·관통·유도 스킬의 피해 등을 올린다. 재료의 치명타 능력은 계승하지만 진화 자체가 새로운 치명타 동작을 만들지는 않는다.

아트가 암시하는 기능과 실제 작동을 맞춰야 한다.

## 재설계 기준과 예시

32종은 유지하되 각 파츠에 짧게 설명할 수 있는 대표 규칙 하나를 둔다. 같은 계열도 조건, 대상 선택, 자원 사용, 후속 보상 중 하나가 달라야 한다. 액티브를 직접 사용하는 행동을 보조하고, 파츠가 독립 공격을 계속 생성하는 구조는 피한다.

아래는 신규 구현이 필요한 방향 예시다.

| 파츠 | 독자성을 주는 예시 |
|---|---|
| 룬 조준경 | 같은 적을 연속으로 맞히는 투사체 스킬에 보상 |
| 갈대 관 | 가까운 적보다 멀리 날아간 투사체 스킬에 보상 |
| 메아리 방울 | 서로 다른 QWER을 이어 쓰면 처음 쓴 슬롯의 대기시간을 일부 회수 |
| 중력석 | 직접 사용한 끌어당김 스킬의 집결 성능을 강화 |
| 서리 결정 | 제어 상태가 끝나기 전에 다음 스킬을 맞히는 타이밍에 보상 |
| 바람 장화 | 이동 스킬 종료 직후 다음 스킬을 사용할 때 보상 |

T2~T5의 144개를 모두 별개 동작으로 늘리기보다, 계열 쌍 36개가 서로 다른 합성 목적을 갖고 4등급이 그 동작을 강화하도록 설계하는 편이 이해하기 쉽다. 개별 T1 재료의 능력 계승과 새 대표 규칙의 계승 방법을 함께 정해야 하며, T5에 재료 16개의 규칙을 전부 붙여 설명과 전투를 복잡하게 만들지 않아야 한다. 대표 규칙은 실제 조작·명중 확인이 가능한 소수로 제한한다.

## 설명 표시 수정

T2 이상 설명을 기본 효과 → 진화 발동 조건 → 추가 효과 → 합성 재료 → 다음 합성 순서로 표시한다. 두 조건은 모두 만족해야 한다고 명시하며, 같은 조건의 중복 표시를 제거했다. 기술 용어인 시전·환급과 반복되는 내부 처리 문장을 줄이고, 실제 적용되는 수치를 효과마다 한 줄씩 보여준다. 능력 수치는 변경하지 않았다.

실제 Game 씬의 T2/T5 설명 상단·하단을 임시 세이브/AI 비활성 상태로 캡처해 확인했다. 실 API 호출과 이미지 제작은 하지 않았다.
