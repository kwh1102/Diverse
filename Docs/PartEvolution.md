# 파츠 진화

합성은 같은 등급 두 개를 소비해 T2~T5를 만드는 방식이다. 보상에는 T1 32종만 나온다. 서로 다른 종류도 합성할 수 있다.

재료 능력을 계승하고 **조건부 진화 특성과 별도 진화 그림**을 추가한다. 진화 특성은 수동 액티브만 보조하며 자동 공격을 만들지 않는다.

T1 32종을 이름에 맞는 고유 능력으로 개편했다. [파츠 도감](Parts.md)과 [검토 기록](PartAudit.md)을 참고한다. 현재 144개 진화 정의는 계열 쌍 36개의 4등급 버전이며, 각각이 별도 스킬을 시전하지는 않는다. 실제 합성의 동작 차이는 재료에서 계승한 고유 능력으로 만들어진다.

인벤토리 설명은 재료에서 계승한 고유 능력 → 진화 발동 조건 → 진화 추가 효과 → 합성 재료 → 다음 합성 순서다. 각 고유 능력은 설명에 적힌 상황에서 발동하고, 진화 효과는 스킬 사용 시 표시된 조건을 만족해야 추가된다. 두 조건이 표시되면 모두 만족해야 한다. 같은 조건을 두 번 검사하는 진화도 화면에서는 한 번만 표시한다.

## 결과 결정

1. 모든 T1 재료의 ID와 개수를 보존한다. 합성 순서와 관계없이 같은 구성은 같은 능력이 된다.
2. 재료의 고유 동작을 모두 계승한다. 비율형 수치는 T1 값 × 해당 재료 수 / 전체 재료 수 × 등급 예산으로 계산한다. 현재 예산은 1 / 1.8 / 3 / 4.5 / 6.4다. 고정 발동 조건·대기시간은 유지하고 같은 고유 능력의 총강도는 2배까지다. 관통 같은 정수 동작에는 최소 1회와 별도 상한을 적용한다.
3. 개수 합계가 가장 많은 두 계열을 선택한다. 동률은 계열 문자열의 ordinal 정렬 순서로 결정한다. 한 계열뿐이면 순수 진화다.
4. 두 계열 + 등급으로 미리 정의된 특성과 전용 그림을 찾는다. 두 주요 계열의 전체 재료 비율을 특성 수치에 곱한다. 나머지 재료도 기본 능력을 모두 계승한다.
5. 같은 계열 조합·등급은 그림과 이름을 공유한다. 상세 설명의 재료 목록과 계승 능력이 개별 조합을 구분한다. 전체 장착 상한은 유지한다.

예: 집중 렌즈 + 수호 버클 → **T2 가호의 렌즈**. 정지 후 액티브 첫 적중 피해 +27%, 완벽한 회피 성공 시 공격력의 31.5% 보호막을 각각 계승한다. 보호막이 있거나 보호막·장벽 단계가 있는 액티브에는 별도 진화 보너스(해당 시전 피해 4.55%, 공격력의 6.5% 보호막, 첫 적중 회복 0.52%)도 적용한다. 렌즈와 버클의 서로 다른 동작을 보존하므로 무조건 피해·보호막 수치만 더하는 이전 방식과 다르다.

위력은 충전/R, 치명타는 정밀 동작, 재사용은 다른 슬롯 연속 사용, 투사체는 투사체 단계, 범위는 먼 위치 조준, 제어는 제어 단계, 방어는 보호막/방어 단계, 이동은 이동 단계와 연결된다. 혼합 진화는 두 조건을 함께 요구하며 위력 혼합은 상대 계열 조건을 따른다.

진화 조건은 액티브를 사용할 때 검사한다. 피해·거리·제어·첫 적중 회복과 재료 고유 능력은 **각 시전의 별도 문맥**에 저장한다. 중첩 시전이 서로 덮어쓰지 않는다. 쿨다운 회수는 해당 시전에 한 번 적용한다. 무기 교체·시전 취소로 모래시계의 빗나감 보상을 얻을 수 없다. 피해·사거리·제어·쿨다운 회수·보호막·회복에 별도 총합 상한이 있다. 서리의 짧은 빙결이 원래 더 길던 기절을 줄이지 않으며 보스 기절 저항도 유지한다.

## 그림과 편집

8계열의 순서 없는 같은/다른 계열 쌍 36종 × T2~T5 = 144종. T1 32종과 합쳐 **176개 전용 그림**을 제작했다. T2 이상은 두 계열을 융합한 하나의 새 도구이며, 같은 계열 쌍은 T2~T5에 걸쳐 실루엣과 재질이 발전한다. T1은 64×64, 진화는 96×96 알파 투명 PNG다. 원본에서 다시 가져와 가장자리와 재질 톤을 정리하고, 표시할 때도 이미지 여백을 보존한다. 전용 그림이 없으면 준비 중 아이콘을 표시한다.

수치·명칭·경로는 `AbilityRules.asset / evolutions`에서 편집한다. `Tools/author_part_evolutions.py`는 초기 144개 정의와 제작 목록을 다시 작성하는 **저작 도구**다. Inspector에서 수정한 진화 값을 덮어쓰므로 일반 도감 갱신에는 `Tools/export_wiki.py`만 사용한다.
