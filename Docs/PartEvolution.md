# 파츠 진화

합성은 같은 등급 두 개를 소비해 T2~T5를 만드는 방식이다. 보상에는 T1 32종만 나온다. 서로 다른 종류도 합성할 수 있다.

재료 능력을 계승하고 **조건부 진화 특성과 별도 진화 그림**을 추가한다. 진화 특성은 수동 액티브만 보조하며 자동 공격을 만들지 않는다.

## 결과 결정

1. 모든 T1 재료의 ID와 개수를 보존한다. 합성 순서와 관계없이 같은 구성은 같은 능력이 된다.
2. 기본 능력은 T1 값 × 해당 재료 수 / 전체 재료 수 × 등급 예산으로 계승한다. 현재 예산은 1 / 1.8 / 3 / 4.5 / 6.4다.
3. 개수 합계가 가장 많은 두 계열을 선택한다. 동률은 계열 문자열의 ordinal 정렬 순서로 결정한다. 한 계열뿐이면 순수 진화다.
4. 두 계열 + 등급으로 미리 정의된 특성과 전용 그림을 찾는다. 두 주요 계열의 전체 재료 비율을 특성 수치에 곱한다. 나머지 재료도 기본 능력을 모두 계승한다.
5. 같은 계열 조합·등급은 그림과 이름을 공유한다. 상세 설명의 재료 목록과 계승 능력이 개별 조합을 구분한다. 전체 장착 상한은 유지한다.

예: 집중 렌즈 + 수호 버클 → **T2 가호의 렌즈**. 액티브 피해 7.2%, 시전 보호막/공격력 16.2%를 계승한다. 보호막 보유 또는 보호막·장벽 단계가 있는 수동 액티브에 피해 4.55%, 보호막/공격력 6.5%, 첫 적중 회복/공격력 0.52%의 진화 보너스를 부여한다. 적용 여부는 시전 시점에 확정한다.

위력은 충전/R, 치명타는 정밀 동작, 재사용은 다른 슬롯 연속 사용, 투사체는 투사체 단계, 범위는 먼 위치 조준, 제어는 제어 단계, 방어는 보호막/방어 단계, 이동은 이동 단계와 연결된다. 혼합 진화는 두 조건을 함께 요구하며 위력 혼합은 상대 계열 조건을 따른다.

기본 시전 보호막 적용 후 조건을 검사한다. 피해·거리·제어·첫 적중 회복은 **각 시전의 별도 문맥**에 저장한다. 중첩 시전이 서로 덮어쓰지 않는다. 쿨다운 환급은 해당 시전의 남은 쿨다운에 한 번 적용한다. 피해·사거리·제어·쿨다운 환급에 별도 총합 상한이 있다. 보호막·회복은 계승 능력과 상한을 공유한다. 사거리·제어는 기존 장착 총합 상한도 넘지 않는다.

## 그림과 편집

8계열의 순서 없는 같은/다른 계열 쌍 36종 × T2~T5 = 144종. T1 32종과 합쳐 **176개 제작 대상**이다. T2 이상은 재료 사진을 붙이지 않고 하나의 새 도구로 그린다. 이미지 생성은 보류되어 있으며, 전용 그림이 없으면 준비 중 아이콘을 표시한다.

전체 정의: [로컬 위키](Wiki/index.html), [진화 CSV](PartEvolutions.csv), [제작 매니페스트](../ArtSource/Parts/image_manifest.csv).
