## 합성과 계승

같은 등급 두 개를 합치면 T2~T5로 오른다. 같은 종류도 가능하다. 모든 T1 재료 ID와 개수를 보존하며 합성 순서가 달라도 재료 구성이 같으면 결과가 같다. 재료의 고유 동작을 계승하고 수치의 기여는 `재료 수 / 전체 재료 수 × 등급 예산`으로 계산한다. 고정 횟수·발동 조건은 유지한다. 관통 횟수는 소량의 재료도 최소 1회를 계승하며 강화 상한을 적용한다.

등급 예산은 1 / 1.8 / 3 / 4.5 / 6.4이며, 동일 고유 능력은 여러 파츠에 나뉘어 있어도 강도 합계 2배까지다. 추가 피해·치명타·대기시간 회수·회복·보호막·이동에는 별도 총합 상한이 있다. 같은 전체 재료 구성의 중복 장착은 하나만 적용한다.

합성의 계열 쌍 36종 × 4등급 = 144개 이름·아트와 조건부 진화 보너스를 유지한다. 같은 외형도 구성 재료에 따라 계승 동작이 다르며, 144개가 서로 다른 독립 스킬 144개라는 뜻은 아니다.

전투 중 충전·중첩·임시 준비 상태는 삶/저장 복원 시 초기화된다. 파츠가 스스로 새 스킬을 시전하거나 공격을 무한 반복하지 않는다. 투사체 보정·화상은 직접 사용한 액티브에만 붙는다.

## 편집과 제작

`AbilityRules.asset / parts`에서 고유 능력·초반 등장 여부·수치·문구·아트 모티프, `partTraits`에서 상한을 편집한다. 기존 재료 ID는 보존하므로 세이브의 합성 구성은 새 능력을 계승한다. T1 32종과 진화 144종의 전용 투명 PNG를 제작해 연결했다. [제작 기록](../ArtSource/Parts/README.md), [파츠 진화](PartEvolution.md), [위키](Wiki/index.html)를 참고한다.

`author_part_catalog.py`는 이전 수치형 파츠의 초기 저작 도구로 현재 데이터에 실행하면 안 된다. `author_part_traits.py`도 의도적으로 능력을 재저작할 때만 사용한다. 도감 갱신은 `export_wiki.py`다.
