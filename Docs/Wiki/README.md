# Diverse 로컬 개발 위키

`index.html`을 브라우저에서 열면 된다. 서버·패키지 설치·로그인이 필요 없다. `catalog.js`를 일반 스크립트로 읽으므로 `file://`에서도 동작한다. 검색, 분류, 계열·등급 필터, 항목별 원본 데이터, 무기 칸 그림, 합성 탐색기를 제공한다.

| 목록 | 편집 원본 |
|---|---|
| T1 파츠 32종, 진화 외형·특성 144종, 무기 유형 5종 | `Assets/_Project/Data/AbilityRules.asset` |
| 무기·적·코스튬·공격 유형·월드 테마·아트·월드 규칙 | `Assets/_Project/Data/**/*.asset` |
| 인벤토리·성장·아이템 비용·물약 수치 | `Assets/_Project/Resources/GameDatabase.asset` |
| 액티브 언어·검증·요청 필수 조건 | `Assets/_Project/Scripts/Combat/ActiveSkillGenerator.cs`, `ActiveSkillRequest.cs` |
| 아이템·이동·원소·스탯 등 전체 enum 선언 | `Assets/_Project/Scripts` 아래 에디터를 제외한 C# |
| 실제 파츠 이미지 176개 제작 대상 | `ArtSource/Parts/image_manifest.csv` |

이 위키는 파일의 **스냅샷**이다. 원본 변경 후 프로젝트 루트에서 `python Tools/export_wiki.py`를 실행하고 페이지를 새로 고침한다. 이 도구는 원본 게임 데이터를 수정하지 않는다. Python 표준 라이브러리만 사용한다. 액티브 언어 번역표는 언어 확장 시 함께 갱신한다.

중첩 필드는 ‘원본 데이터 전체 보기’에서 모두 확인한다. 상단 필드 요약은 반복되는 중첩 필드를 생략한다. 원본 링크는 로컬 파일로 연결되므로 브라우저가 다운로드하거나 소스로 표시할 수 있다. Unity Inspector에서 해당 경로를 찾아 편집할 수 있다.

합성 탐색기는 T1 두 개를 선택해 합성하고 결과를 A/B에 다시 넣어 T5까지 조합한다. 같은 결과를 양쪽 칸에 넣으면 동일 구성끼리의 합성도 볼 수 있다. 실제 게임의 재료·골드·세이브에 영향을 주지 않는다.

32종 T1의 모든 재료 구성은 매우 많으므로 개별 레시피를 전부 열거하지 않는다. 계열 조합 36종 × T2~T5 4등급의 **외형·진화 특성 정의 144종**을 열거한다. 같은 외형을 공유해도 개별 재료 능력과 비율은 유지된다.

현재 그림은 생성 보류 상태다. T1은 기존 임시 그림이며, T2 이상 전용 그림이 없는 항목에는 빈 그림 표시가 나온다. 실제 이미지 생성은 다른 세션에서 진행한다. ‘시스템 문서 → 파츠 이미지 생성 프롬프트’에서 최신 제작 지침을 확인한다. 합성 탐색기도 개편된 재료 고유 능력과 개별 상한을 표시한다.
