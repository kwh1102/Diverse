# 월드: 5방향 영역 · 테마 · 지형 · 배치

현재 아트와 배치 기준은 [WorldArt.md](WorldArt.md)에 정리한다. 커스텀 월드 모드는 사용하지 않는다.

## 생성 순서

1. `ZoneMap`: 중앙 스폰과 5방향 영역. 8개 전투 유형에서 5개를 중복 없이 선택하고, 전투 유형과 환경 테마는 별도로 저장한다.
2. 랜드마크/경계 관문: 지형보다 먼저 목적지와 전투 공간을 결정한다.
3. `Terrain`: 여러 청크에 걸친 산맥, 자연스러운 고개, 고원, 강/호수와 길. 전투 영역 경계가 지리적 벽이 되지 않는다.
4. `WorldGen.GroundAt`: 넓은 재질 구획, 일관된 포장과 길, 테마의 액체. 작은 노이즈 조각으로 바닥을 섞지 않는다.
5. `SceneryLayout`: 군집과 빈터, 길/구조물/가장자리 여유 공간, 스프라이트 간격을 검사한 뒤 장식 배치.
6. `TileBaker`: 연결된 윗면/벽면/물가를 공통 픽셀 규칙으로 렌더링. 이동 중에는 `TileBaker.Operation`으로 시간을 나눠 처리한다.

모든 절차는 시드와 월드 좌표로 결정된다. 이웃 청크의 로딩 순서로 지형이나 장식 결과가 바뀌지 않는다. 큰 지형은 청크에 종속되지 않는다.

## 전투 유형과 환경 테마

| 전투 유형 | 기본 테마 | 랜드마크 | 액체 |
|---|---|---|---|
| 근거리 공속 | 증식의 숲 | 태고의 고목 | 물 |
| 근거리 극딜 | 붕괴의 화산지대 | 분화의 심장 | 용암 |
| 원거리 공속 | 공명의 수정평원 | 공명탑 | 물 |
| 원거리 극딜 | 침묵의 빙하지대 | 얼음성 | 걸어서 건너는 얼음 |
| 이동속도 | 질풍의 협곡 | 바람탑 | 물 |
| 탱킹 | 불굴의 요새 | 불굴의 성채 | 물 |
| 회피 | 뒤틀린 거울유적 | 거울 궁전 | 물 |
| 광역 | 군체의 늪 | 군체의 신전 | 독늪 |

`CombatTypes/*.asset`의 기본 테마와 `WorldSave.zoneThemes`의 저장된 테마를 별도로 다룬다. 전투 유형의 혼합 가중치와 시각적 재질의 선택도 분리되어 있다.

## 높이와 가독성

정면 축의 탑다운 RPG 표현. 타일 축은 기울이지 않고, 한 단을 화면 위로 16px 옮겨 윗면과 정면 벽을 그린다. 바닥과 절벽의 각진 큰 윤곽에 작은 모서리 깎기를 적용한다. 윗면은 `ThemeDef.cliffTop`, 벽 재질과 명암은 `ArtStyle.cliffs`에서 정한다. 지면 노이즈로 윗면의 재질을 매 칸 바꾸지 않는다.

절벽, 그 뒤로 가려지는 땅은 이동/투사체를 차단한다. 계단이나 높은 곳을 직접 오르는 새 이동 기능은 이번 아트 개편에 포함하지 않는다.

## 적과 구조물

`EnemySpawner`는 화면 밖 고리에 테마별 소규모 무리를 만들고 멀어진 적을 해제한다. 보스는 랜드마크·관문·소굴에 배치한다. 적의 종류/AI/능력치는 이번 아트 개편에서 새로 설계하지 않는다.

구조물의 소품은 진입로를 가진 배치로 구성한다. 일반 지형의 장식은 구조물 주변에 들어오지 않는다. 작은 풀은 지면에 구워 그려 렌더러/오브젝트 수를 줄인다.

## 편집과 검증

- `Data/WorldRules.asset`: 산맥 간격/폭, 고개, 강/호수, 길, 장식 간격, 스폰 규칙.
- `Data/Themes/*.asset`: 지면/윗면/액체, 장식 목록, 랜드마크, 적 목록.
- `Data/ArtStyle.asset`: 팔레트, 무늬 밀도, 절벽 높이/모서리, 그림자.
- `ArtSource/WorldOverhaul`: 현재 원본과 프롬프트/관리 목록. 큰 시트는 게임에서 직접 로드하지 않는다.
- `Resources/Sprites`: 실제 픽셀 크기로 가져온 PNG. 에디터 메뉴 **Diverse → Art → Apply Cute World Overhaul**로 재현한다.

**Diverse → World → Overview Maps and Checks**는 3개 시드의 지형 비율, 접근성, 모든 랜드마크 도달 여부와 결정성을 검사한다. `Logs/World/report.txt`에 기록한다. **Diverse → Art → Check World Overhaul**은 청크 접합, 장식 간격/역순 결과, 픽셀 규격과 시간 분할 렌더링을 검사한다.

실제 게임 검토는 `Scenes/Game.unity`에서 Play하거나 **Capture All Terrain Regions**로 촬영한다. 촬영/스모크/성능 검증은 별도의 저장 경로를 쓰며 실제 사용자 세이브를 수정하지 않는다.
