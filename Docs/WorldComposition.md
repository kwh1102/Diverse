# 지역 공간 구성 개편

광장/시작 초원을 제외한 8개 테마에 적용한다. 새 세계가 8개 중 5개 지역을 선택하는 규칙과 기존 세계의 저장된 선택은 유지한다. 원본 PNG와 캐릭터 크기는 바꾸지 않는다.

## 테마별 오브젝트 분석과 구성

각 테마의 기존 자연물 4종(나무/바위/덤불/지면 풀), 지역 장식 4종, 탐험 소품 4종을 모두 분류했다. `Canopy`는 나무뿐 아니라 큰 결정처럼 풍경의 윗부분을 만드는 큰 덩어리를 포함한다. `Supply`는 일반 필드 확률을 0으로 설정하고 장소 안에 배치한다.

| 테마 | 큰 덩어리와 군집 | 작은 장소에 묶는 소품 |
|---|---|---|
| 증식의 숲 | 큰 활엽수, 넓은 잎, 양치류, 버섯, 이끼 낀 고목 | 쓰러진 고목 주변의 버섯/열매/큰 잎 공터 |
| 화산 | 불탄 나무, 분출구, 검은 광석과 암석 | 폐화로 + 광석 수레 + 광석 + 보관 상자 |
| 수정 | 큰 청색 결정, 작은 결정, 보라색 정동 | 결정 + 관측 삼각대 + 보석 돌무더기 + 정동 |
| 빙하 | 큰 침엽수, 얼음 돌탑, 얼어붙은 덤불 | 천막 + 썰매 + 보급 상자 + 얼음 표식 |
| 협곡 | 선인장, 사암 조각과 부러진 기둥 | 바람 표식 + 기둥 잔해 + 항아리 + 선인장 |
| 요새 | 탑/벽/열주 잔해, 높은 땅의 수목 | 방벽 + 깃발 + 훈련 허수아비 + 보급 상자 |
| 거울 | 기둥/석판 군집, 높은 땅의 결정 수목 | 깨진 거울 + 기둥 + 석등 + 룬 석판 |
| 늪 | 큰 버드나무, 갈대, 버섯, 이끼 그루터기 | 그루터기 + 채집꾼 표식 + 버섯 + 갈대 |

## 배치와 크기

`ThemeDef.scenery`에 숲/광물 지대 크기, 군집 문턱, 경계 폭, 빈터, 고립 개체 확률, 수관 간격, 지면 변화, 건축물 크기와 작은 장소 구성을 둔다. `DecorEntry.role`, `visualScale`, `scaleVariation`로 개체별 역할과 크기를 편집한다.

`SceneryHabitat`의 월드 좌표 패치를 식생/광물과 지면 음영이 공유한다. 군집 안과 밖의 밀도를 달리하고 더 작은 빈터 필드를 겹친다. 일반 후보는 역할별 가중치를 정규화해 선택하므로 목록 앞의 소품이 나무의 확률을 잠식하지 않는다. 수관의 부분 겹침과 밑동 간격은 별도로 검사하며 후보 조회 범위는 실제 확대된 이미지에서 계산한다.

큰 자연물은 기본 약 2배에 개체별 편차, 집/천막과 탐험 중심물은 1.5배, 지역 랜드마크는 1.4배로 표시한다. 시작 광장/초원은 기존 크기를 유지한다. 접지 피벗과 밑동 충돌은 이미지 전체 크기와 분리한다. 큰 환경물 뒤에 주인공이 들어가면 해당 이미지가 반투명해졌다 복원된다.

### 선인장·수정 크기 보정

나무의 크기는 유지한다. 나무 키를 사용하는 `tree_Dunes_*` 선인장과 `tree_Crystal_*` 수정도 실제 물체의 종류에 맞춰 구분한다. 협곡의 큰 선인장 장식/꽃 선인장과 수정 지역의 큰 결정 장식/광물 부채에도 같은 규칙을 적용한다.

| 크기 | 선인장 (이전 대비) | 수정 (이전 대비) | 배치 |
|---|---|---|---|
| 일반 | 65% | 55% | 기본 크기, 기존 개체별 편차 유지 |
| 중간 | 80% | 80% | 군집 밀도 0.5 이상에서 후보의 22%; 소품 묶음의 중심 결정에도 적용 |
| 거대 | 100% | 100% | 군집 중심부(밀도 0.75 이상)에서 후보의 4% |

`DecorEntry`의 `visualScale`, `mediumScale`, `rareScale`, 크기별 확률/문턱을 Inspector에서 편집한다. `spacingScale`은 이전 간격을 예약하므로 작은 개체가 늘어나거나 빈터가 메워지지 않는다. 크기 선택은 월드 좌표와 시드로 고정된다. 건축물·랜드마크·도로는 이 보정의 대상이 아니다.

**Diverse → World → Apply Cactus and Crystal Sizes**는 협곡/수정의 대상 항목만 보정한다. 전체 지역 설정을 다시 설치해도 이 크기 보정을 유지한다. 컴파일 및 기존 8테마 역순/간격/청크 검사 통과, 고밀도 표본 1,000개당 거대 크기 40개·군집 밖 큰 개체 없음 확인. 기존 표본의 협곡/수정 배치 개수 71/69개도 동일하다. 두 지역 실제 Game 씬 촬영과 필드→도로/소품 묶음 길찾기도 통과했다. 최신 실행 기록은 `Logs/NaturalSizesChecks.log`, `Logs/NaturalSizesCapture.log`다.

소품 묶음은 전역 셀에서 결정하고 구성원 전체가 지형/도로/구조물 여유 검사에 통과한 경우에만 배치한다. 묶음 주변은 일반 장식을 비우며, 구성원은 각자의 밑동이 속한 청크에서 한 번씩 만든다. 청크 로딩 순서나 아직 로딩되지 않은 이웃 청크가 결과에 영향을 주지 않는다.

## 길

광장 내부 건물과 포장을 유지하고 기존 접근 방향 중 3곳을 사용한다. 출구 바깥의 비대칭 분기 거점에 목적지를 가까운 순서로 연결한다. 모든 목적지가 광장에 직접 연결되는 방식은 사용하지 않는다. 일부 지역 사이에는 좁은 우회로를 추가한다. 산맥의 원래 능선과 물을 샘플링해 굴곡 후보를 고른 뒤 실제 도로의 통행 여유를 지형에 반영한다. 이 순서는 지형/도로 생성 재귀를 방지한다.

길의 폭은 주도로/분기/우회로로 구분하며 장식 여유와 지형 개방도는 실제 도로 가장자리에서 계산한다. 조정 위치는 `WorldRules.asset`의 Roads와 Scenery composition이다.

탐험 장소마다 반복되던 네 방향 십자 샛길도 없앴다. 남쪽 입구에서 주변 도로를 향해 하나의 접근로를 내고, 장소의 벽을 가로지르지 않도록 바깥에서 꺾는다. 가까운 도로에는 직접 연결하고, 먼 곳은 도로에 더 가까운 이웃 장소로 이어진다. 이웃이 없는 외딴 곳은 짧은 방향성 샛길을 남긴다. 도로까지의 거리가 감소하는 이웃만 고르므로 순환 의존은 없다. `explorationTrailConnectDistance`, `explorationTrailNeighbourDistance`, `explorationTrailBend`로 범위와 바깥 여유를 조정한다.

## 확인과 검증

`Assets/_Project/Scenes/Game.unity`를 열고 Play. 기존 실행 중인 월드는 종료 후 다시 시작해야 새 캐시와 생성 규칙이 적용된다. 개별 테마의 수치와 소품 묶음은 `Assets/_Project/Data/Themes/*.asset`의 Scenery에서 편집한다.

- `Diverse → World → Apply Regional Composition`: 8개 테마와 공통 길/배치 설정을 명시적으로 재설치한다. 사용자 조정값을 초기값으로 바꾸므로 일반 확인을 위해 실행할 필요는 없다.
- `Diverse → World → Check Regional Composition`: 8개 테마의 역할/스케일/소품 묶음, 역순 생성, 접지/간격, 길 여유와 여러 시드의 목적지 연결을 검사한다. 기존 아트/청크 경계/시간 분할 렌더 검사도 포함한다.
- `CompositionCapture.RunBatch`: 별도 임시 저장으로 실제 Game 씬의 테마별 필드/소품 묶음/랜드마크를 촬영하고 청크 경계와 소품 묶음 중앙 길찾기를 검사한다. 출력은 `Logs/Composition/`.
- `WorldOverview.RunBatch`: 전체 지형의 시작점 연결성 및 보스/탐험 장소 접근, 역순 타일 생성과 미니맵 크기 지형 그림을 확인한다. 출력은 `Logs/World/`.

이 변경은 같은 시드의 도로와 장식 결과를 바꾼다. 실제 사용자 저장 파일을 수정하거나 다시 저장하는 검증은 하지 않는다.
